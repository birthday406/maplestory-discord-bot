# 샤벳 개인정보 문의 처리

공개 원문은 `website/dist/policies.json`이며 봇과 홈페이지가 함께 사용합니다. 공개 연락처는 valentineday302@gmail.com입니다.

## 삭제·정정 요청

1. 요청 범위와 Discord 사용자 ID 또는 서버 ID를 확인합니다. 비밀번호·토큰·신분증을 요구하지 않습니다. 필요하면 해당 Discord 계정이나 서버 관리 권한으로 요청자임을 확인합니다.
2. 개인 랭킹 연결은 `ranking_preferences`와 `ranking_recent_characters`의 해당 `discord_user_id`를 대상으로 확인합니다. 공개 캐릭터 기록이나 다른 이용자의 기록을 함께 삭제하지 않습니다.
3. 서버 설정은 요청자의 관리 권한과 대상 채널·역할을 확인해 정리합니다. 문의 메일·오류 기록·전송 기록 등 다른 보관처도 요청 범위에 맞춰 검토합니다. 자동 삭제 기능이 있는 것으로 안내하지 않습니다.
4. 실제 삭제는 대상·범위를 운영자가 확인하고 승인한 뒤 수행합니다. 불필요한 개인정보가 담긴 별도 백업을 새로 만들지 않습니다. 처리 결과나 보관이 필요한 사유를 회신합니다.
5. 랭킹 DB 주간 백업은 최근 4개 순환 보관입니다. 요청 처리 기록은 접근을 제한해 보관하고, 백업 복구 시 서비스를 다시 열기 전에 삭제·정정 요청을 재반영합니다. 요청 기록도 후속 처리에 필요하지 않게 되면 정리합니다.

## 공개 전 확인

- 공개 도메인 확정 후 Discord Developer Portal에 `/#terms`, `/#privacy`의 실제 HTTPS 주소를 등록합니다. 로컬 주소를 등록하지 않습니다.
- 메일 수신 여부와 운영 담당자의 접근을 확인합니다.
- 서버 지역·외부 업체 계약 및 적용 법령에 따른 국외 처리 고지 세부사항은 공개 운영 환경에 맞춰 검토합니다. 이 문서는 법률 검토 완료를 의미하지 않습니다.
- 유료화·새 외부 API·분석 도구 등 처리 방식이 바뀌면 원문과 변경일을 함께 갱신합니다.
