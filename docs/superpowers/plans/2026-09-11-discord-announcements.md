# 공식 Discord 공지 수집 구현 계획

목표: 공식 announcements의 새 글·수정을 보조 1번에서 수집하고 메인 봇이 중복을 제외해 한국어로 전달한다.

사용자 승인 설계: 홈페이지 알림 유지, 이미 보낸 공식 게시글의 단순 소개는 제외, 새 정보는 전달. 번역 10초 초과 시 원문을 먼저 게시하고 같은 메시지를 갱신한다. 최초 관측은 기준점으로만 저장한다. 수집 검증 전 자동 게시·팔로우 해제는 하지 않는다.

## 작업과 검증

- [x] `discord_news.py`: 입력 검증, SQLite 변경·전송 기록, 공식 게시글 ID 기반 단순 소개 제외, 번역 대기·메시지 수정. `test_discord_news.py`로 최초 기준점, 재시작, 수정, 중복, 실패 복구 검증.
- [x] `discord_news_collector.py`와 `discord_news_dom.js`: 화면에서 관측한 메시지 DOM만 추출. 본문·링크·첨부·UTC 작성 시각과 메시지 ID 수집. 프로필은 별도 디렉터리에 저장하며 토큰·쿠키 추출 금지. 실제 로그인 화면·채널 접근 검증 필요.
- [x] `maple_bot.py`: 명시적 환경변수로 활성화하는 독립 처리 루프. 수집 실패·장기 미수신은 관리자 상태 알림. 검증 모드에서는 번역·게시하지 않는다.
- [x] 별도 requirements, 보조 서비스 예시, README·PROJECT_RULES·CHANGELOG·gitignore 갱신. 기존 랭킹 전송 함수를 선택적 목적지 인자로 재사용.
- [ ] 관련 테스트와 전체 테스트 실행. 보조 1번 브라우저 설치·로그인 및 수집 검증을 진행한 후 자동 게시 활성화 단계로 넘어간다.

제약: Python 3.10+, 기존 봇 가상환경과 수집용 브라우저 환경 분리. 게시 대상은 기존 공지 채널. 브라우저 프로필·수집 DB·원본은 Git 제외. 파일 삭제·전역 설치·서비스 등록은 프로젝트 승인 원칙을 따른다. 로그에 인증·프로필 내용을 남기지 않는다.

한계: Discord 화면에 로드되지 않은 오래된 수정은 실시간 감지가 보장되지 않는다. 화면 구조·로그인 만료를 실패 상태로 드러낸다. 사용자 계정 자동화의 서비스 약관상 제재 위험은 사용자가 이미 안내받았다.

검증 결과: 2026-09-11 로컬 전체 테스트 414개 통과. 최초 기준점, 재시작, 수정, 첨부 URL 만료 서명 변화, 홈페이지 단순 소개, 채널별 실패 독립성, 원문 우선 전송 후 편집, 검증 모드 미게시를 확인했다. 서버 설치·로그인·브라우저 실동작은 대기 중이다.
