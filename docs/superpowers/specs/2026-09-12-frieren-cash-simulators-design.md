# 프리렌 캐시 시뮬레이터 설계

## 목표

현재 GMS v.271 판매 구성을 기준으로 프리렌 시그니처 스타일 컬렉션과 Heroic 월드 프리렌 원더베리를 Discord에서 실제 확률로 체험할 수 있게 한다.

## 명령과 개봉 수량

- `/시그니처` (`/signature`): 1회 또는 5회 개봉한다. 판매 단위는 1개 7,900 NX와 10개 79,000 NX이지만 실제 사용 화면의 최대 개봉 수량은 5개다.
- `/원더베리` (`/wonderberry`): 1회 또는 5회 개봉한다. 판매 단위는 1개 4,000 NX와 11개 40,000 NX다.
- 두 명령 모두 명령 실행자만 사용할 수 있는 `다시 뽑기`와 `기대값 계산하기` 버튼을 제공한다.

## 확률 데이터

- 시그니처는 Nexon general-post 44219, 원더베리는 general-post 5674의 API 본문을 명령 실행과 다시 뽑기마다 읽는다.
- 시그니처 표는 아이템명과 확률을, 원더베리 표는 아이템명·기간·확률을 보존한다.
- HTML 표가 바뀌거나 비어 있으면 임의 확률로 추첨하지 않고 사용자에게 재시도 안내를 보낸다.

## 화면

- 시그니처는 기존 `/스스비`의 한 메시지·한 합성 이미지 구조를 사용하되 별도 가격, 제목, 색상과 프리렌 대표 아이콘을 사용한다.
- 원더베리는 GMS 클라이언트 `UIGachapon.img/wonderBerry`에서 추출한 일반·특별 슬롯과 배경 효과를 사용한다. 1회는 큰 슬롯, 5회는 게임처럼 가로 슬롯으로 표시한다.
- 원더베리의 영상 원본은 클라이언트 전용 비디오 형식이고 Discord 결과 확인에는 필요하지 않으므로, 최종 결과 화면을 정적 PNG로 재현한다.
- 아이콘은 GMS 클라이언트의 Cash·Consume·Pet 데이터에서 추출한다. 이름이 새로 바뀌어 아이콘을 찾지 못해도 빈 슬롯과 보상명은 정상 표시한다.

## 비용과 기대값

- 누적 개봉 횟수와 판매 묶음을 고려한 최소 NX 비용을 임베드 하단에 표시한다.
- 기대값 창은 결과별 공식 확률, 평균 개봉 횟수, 평균 구매 비용, 현재 누적 횟수 안에 한 번 이상 획득할 확률을 표시한다.
- 같은 보상이 한 번에 여러 개 나오면 기대값 창에는 한 번만 표시한다.

## 문서와 검증

- 명령 등록, 한국어 도움말, README와 CHANGELOG를 갱신한다.
- 확률표 파싱, 1·5회 제한, 가중치 추첨, 비용 계산, 이미지 크기, 버튼 재추첨과 오류 처리를 테스트한다.
- 기존 `/스스비` 동작과 현재 작업 트리의 랭킹 변경을 보존한다.
