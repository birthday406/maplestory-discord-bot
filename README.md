# 메이플스토리 Discord 공지 봇

메이플스토리 공식 홈페이지의 새 공지 중 `maintenance`, `sale`, `general`, `update`, `events` 카테고리를 Discord 채널에 알려주는 파이썬 봇입니다.

## 봇이 하는 일

1. 5분마다 메이플스토리 공식 뉴스 API에서 새 공지를 확인합니다.
2. 새 공지의 영어 본문을 OpenAI가 3~5줄 영어 요약으로 만듭니다.
3. Google Cloud Translation이 그 짧은 요약을 한국어로 번역합니다.
4. 한국어 요약과 원문 링크를 관리자가 등록한 모든 Discord 채널에 보냅니다.
5. 공식 공지 목록의 썸네일을 Discord 임베드 이미지로 함께 보냅니다.
5. 이미 보낸 공지는 `state.json`에 기록해 다시 보내지 않습니다.

원문 전체를 번역하지 않고 요약만 번역하므로 번역 API 사용량을 줄일 수 있습니다.

실제 `update` 패치노트에 `Sunny Sunday` 표가 있으면 날짜별 혜택을 모두 추출해 전용 임베드 필드와 배너 이미지로 함께 보냅니다. 날짜는 Discord를 보는 사람의 현지 시간으로 표시됩니다. 반복 혜택은 지정된 한국어 표현을 사용하고, 새로운 보상 문구만 Google 번역으로 처리합니다. 제목이 `Preview`인 업데이트 소개 글에는 이 기능이 동작하지 않습니다.

번역된 Sunny Sunday 일정은 `state.json`에 저장됩니다. 각 일정의 시작 시각에는 등록된 당일 알림 채널 모두에 그 주 혜택을 보내고, 24시간 뒤 채널별 자동 메시지를 삭제합니다. `/썬데이`와 `/썬데이목록`은 외부 API를 다시 호출하지 않고 저장된 번역을 사용합니다.

Discord에서 `/썬데이`를 입력하면 현재 진행 중인 일정 또는 가장 가까운 다음 썬데이 메이플 한 건을, `/썬데이목록`을 입력하면 최신 패치노트에서 아직 지나지 않은 일정만 확인할 수 있습니다.

최신 패치노트의 `Cash Shop Transfer`와 `Miracle Time` 표도 `state.json`에 저장합니다. 이미 처리한 최신 패치노트도 5분마다 다시 읽으므로 넥슨이 본문을 나중에 수정해 일정을 추가해도 반영됩니다. `/캐시이동`은 캐시 보관함 이동 시작·종료 시간을, `/미라클큐브`는 남아 있는 날짜별 미라클 타임 대상 장비를 보여줍니다.

`/캐샵`은 최신 공식 `Cash Shop Update` 공지와 캐시샵 데이터 마이닝 페이지 링크를 함께 보여줍니다. 새 `sale` 카테고리의 `Cash Shop Update`가 올라오면 기존 5분 공지 확인 작업이 링크를 `state.json`에 자동 갱신합니다. 다른 판매 공지는 최신 캐시샵 링크를 덮어쓰지 않습니다.

`/핫위크`와 `/큐브세일`은 향후 패치노트 수집을 연결하기 위한 명령어이며, 현재는 진행 중인 이벤트가 없다는 안내만 표시합니다.

## 우르스 골든타임 명령어

`/우르스`는 UTC 01:00~05:00와 18:00~22:00를 기준으로 골든타임 진행 여부를 자동 판별합니다. 미국 서부시간으로는 서머타임에 오전 11시~오후 3시와 오후 6시~오후 10시, 표준시간에 오전 10시~오후 2시와 오후 5시~오후 9시입니다. 임베드의 시각은 Discord 타임스탬프로 표시되어 각 사용자의 현지시간으로 자동 변환됩니다.

관리자가 `/우르스알림`을 켜면 각 골든타임의 시작과 종료 시각에만 알림을 보냅니다. 시작 알림에는 컬러 이미지를, 종료 알림에는 흑백 이미지를 사용하며 중간 시간이나 봇 재시작 시에는 뒤늦은 알림을 보내지 않습니다.

## 메이플 서버 상태 명령어

`/서버`는 넥슨 공식 서버 상태 API에서 글로벌 메이플의 주요 상시 월드인 `Scania`, `Bera`, `Kronos`, `Hyperion`을 확인합니다. 네 월드 모두 로그인 서버가 정상이고 게임 채널이 하나 이상 열려 있을 때 전체 서버를 정상으로 표시합니다. 계절 서버와 상태 데이터가 없는 테스트 서버는 판정에서 제외합니다.

관리자가 `/서버알림`을 켜면 1분마다 상태를 확인하고, 저장된 상태가 점검 중에서 정상으로 바뀐 순간에만 등록된 모든 채널로 서버 오픈 알림을 보냅니다. 첫 실행과 단순 재시작에는 알리지 않으며, 공식 API 오류도 점검 상태로 저장하지 않습니다.

## 글로벌 리부트 보스 5% 명령어

`/5퍼`에서 보스와 난이도를 선택하면 해당 보스의 총 체력과 보상을 받기 위해 전투력 분석에 기록해야 하는 5% 최소 피해량을 인게임 전투분석과 같은 K 단위로 보여줍니다. 제공받은 보스 18종, 난이도별 35개 수치를 선택할 수 있으며, K는 1,000 HP를 뜻합니다. 해당 보스에 존재하지 않는 난이도를 고르면 선택 가능한 난이도를 안내합니다.

## 알림 채널 설정 명령어

아래 명령어는 서버 관리자만 실행할 수 있습니다. `채널`에서는 현재 서버의 텍스트 채널을 선택하고, `동작`에서는 `ON` 또는 `OFF`를 선택합니다. 같은 알리미에 여러 채널을 등록할 수 있습니다.

```text
/공지알림 채널:#공지 동작:ON
/썬데이알림 채널:#메인채팅 동작:ON
/썬데이목록알림 채널:#썬데이메이플 동작:ON
/미라클큐브알림 채널:#메인채팅 동작:ON
/캐시이동알림 채널:#메인채팅 동작:ON
/우르스알림 채널:#메인채팅 동작:ON
/서버알림 채널:#메인채팅 동작:ON
/큐브세일알림 채널:#메인채팅 동작:ON
```

- `/공지알림`: `maintenance`, `sale`, `general`, `update`, `events` 번역 공지
- `/썬데이알림`: 해당 주 Sunny Sunday가 시작될 때 보내고 24시간 뒤 삭제하는 당일 알림
- `/썬데이목록알림`: 새 패치노트에서 전체 Sunny Sunday 목록을 발견했을 때 보내는 알림
- `/미라클큐브알림`: 각 미라클 타임 날짜의 UTC 00:00부터 채널별로 한 번 보내는 당일 알림
- `/캐시이동알림`: 캐시이동 시작 시각부터 24시간 안에 채널별로 한 번 보내는 당일 알림
- `/우르스알림`: 미국 서부의 서머타임을 자동 적용해 골든타임 시작·종료 시각에 보내는 알림
- `/서버알림`: 주요 4개 월드가 점검 중에서 모두 정상으로 바뀔 때 보내는 서버 오픈 알림
- `/큐브세일알림`: 향후 큐브세일 자동 알림을 받을 채널을 미리 저장하는 설정

이미 `ON`인 채널을 다시 켜도 중복 전송하지 않습니다. 목록 알림을 새 채널에 처음 켜면 `state.json`에 저장된 최신 전체 목록을 그 채널에 한 번 보내며, 이후에는 다음 패치노트의 새로운 목록이 나올 때까지 다시 보내지 않습니다.

## HEXA 강화 계산 명령어

Discord에서 `/헥사`를 입력하고 코어 종류, 현재 레벨, 목표 레벨을 선택하면 필요한 솔 에르다와 솔 에르다 조각 합계를 계산합니다.

```text
/헥사 코어종류:강화 코어 현재레벨:7 목표레벨:20
```

지원하는 코어 종류는 `스킬 코어`, `3rd 스킬 코어`, `마스터리 코어`, `강화 코어`, `공용 코어`, `직업군 공용 코어`입니다.
현재 레벨은 0~29, 목표 레벨은 1~30 범위에서 선택할 수 있습니다.

## 채널 추천 명령어

Discord에서 `/채널추천`을 입력하면 메이플스토리 게임 채널 1~40 중 하나를 무작위로 추천합니다. 명령어를 실행한 사용자의 Discord 닉네임과 추천 채널을 함께 공개 메시지로 보여줍니다.

## PSSB 시뮬레이터

Discord에서 `/스스비`를 입력하고 `1회` 또는 `5회`를 선택하면 현재 공식 Premium Surprise Style Box 확률표로 결과를 추첨합니다. 명령어를 실행할 때 공식 표를 새로 읽으므로 구성품 변경을 코드에 직접 입력할 필요가 없습니다.

성별 아이템 두 개가 확률 하나를 공유하면 한 보상으로 합쳐 표시하며, 각 추첨은 독립적이므로 같은 아이템이 중복으로 나올 수 있습니다. 1회와 5회 모두 메시지 한 개로 전송하며, 5회 결과는 실제 GMS SSB처럼 아이콘 다섯 개가 가로로 놓인 이미지 한 장으로 표시합니다. 확률이 2.00% 이하인 아이템은 보라색 슬롯과 `🟪` 표식, 2.00%를 초과하는 아이템은 회색 슬롯을 사용합니다.

배경 광원과 슬롯은 GMS 클라이언트 리소스를 사용하고, 아이템 아이콘은 로컬 WZ 데이터베이스에서 영문명이 정확히 연결되는 일반 장비에 표시합니다. 데이터베이스에 없거나 독립 아이콘이 없는 아이템도 빈 슬롯과 결과 이름은 남습니다.

## 캐시 아이템 검색

Discord에서 `/아이템검색`을 입력한 뒤 영문명, 한글명 또는 아이템 ID를 입력하면 자동완성 목록에서 캐시 아이템을 고를 수 있습니다. 결과에는 GMS 이름, KMS 이름, 분류와 아이템 ID를 표시하며 독립 아이콘이 있는 장비는 아이콘도 함께 보여줍니다.

검색 데이터에는 제공받은 GMS의 캐시 장비 전체가 들어 있습니다. 같은 아이템 ID가 KMS에도 있으면 한글명을 함께 표시하고, 없으면 `KMS 동일 ID 없음`으로 표시합니다. 양쪽 서버에서 이름은 같지만 ID가 다른 아이템은 자동으로 같은 아이템이라고 판단하지 않습니다. 헤어와 성형은 캐릭터 위에 여러 이미지를 합성하는 데이터라 현재는 이름만 표시합니다.

## 캐시 아이템 DB 업데이트하기

GMS 또는 KMS가 패치되면 **봇 프로젝트 폴더에서** 다음 명령을 한 번 실행합니다. 게임 파일 수만 개를 읽기 때문에 몇 분 걸릴 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\update_cash_item_db.ps1
```

기본 게임 폴더가 다른 경우에만 경로를 직접 적습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\update_cash_item_db.ps1 `
  -GmsDataPath "D:\SteamLibrary\steamapps\common\MapleStory\Data" `
  -KmsDataPath "C:\KMS\Maple\Data"
```

도구는 새 `cash-items.tsv`와 `cash-item-icons.zip`을 임시 폴더에서 먼저 완성하고, 아이템·아이콘 개수가 정상인지 확인한 뒤 `data` 폴더의 기존 파일을 교체합니다. `Item` 폴더는 현재 캐시 장비 검색에는 필요하지 않으며, GMS·KMS의 `String` 폴더와 GMS의 `Character` 폴더를 사용합니다.

완료 후 `python -m unittest`를 실행해 봇 테스트가 통과하는지 확인하고 Git에 올리면 됩니다. 이 작업은 Oracle 서버가 아니라 게임 파일이 설치된 Windows 컴퓨터에서 실행합니다.

## 익스트림 성장의 비약 시뮬레이터

Discord에서 `/익성비`를 입력하면 Lv.130~199 캐릭터가 익스트림 성장의 비약을 사용한 결과를 무작위로 추첨합니다.

```text
/익성비 시작레벨:150 개수:10
```

비약을 한 개 사용할 때마다 바뀐 현재 레벨의 확률표로 다음 결과를 추첨합니다. Lv.200에 도달하면 남은 비약은 사용하지 않습니다.

## 성장의 비약 계산기

Discord에서 `/성장의비약`을 입력하고 비약 종류, 시작 레벨, 현재 경험치 퍼센트, 버닝 여부, 사용할 개수를 입력하면 사용 후 레벨과 경험치를 계산합니다. 시작 레벨은 **200~299**만 입력할 수 있습니다.

```text
/성장의비약 비약종류:극성비 · 극한 성장의 비약 시작레벨:245 경험치:37.5 하이퍼버닝:미적용 비욘드버닝:미적용 개수:3
```

현재 지원하는 비약은 익성비, 궁성비, 극성비, 초성비, 전성비입니다. 각 비약의 보장 구간에서는 현재 레벨에 필요한 경험치를 지급하고, 구간을 넘으면 사용자가 제공한 최신 표의 고정 경험치를 지급합니다. 130~199 구간의 익성비 무작위 레벨 상승은 `/익성비`에서, 레벨 200 이상 고정 경험치는 `/성장의비약`에서 계산합니다.

하이퍼 버닝은 한 번 레벨업할 때 5레벨씩 오르되 Lv.260에서 정확히 끝나며, 비욘드 버닝은 Lv.260부터 2레벨씩 오르되 Lv.270에서 정확히 끝납니다. 경험치 퍼센트를 실제 경험치로 환산하므로 소수점 반올림에 따라 실제 게임과 아주 조금 다를 수 있습니다.

## EXP 교환권 계산기

Discord에서 `/exp쿠폰`을 입력하면 일반 EXP 교환권 또는 상급 EXP 교환권을 입력한 개수만큼 사용했을 때의 최종 레벨과 경험치를 계산합니다.

```text
/exp쿠폰 쿠폰종류:상급 EXP 교환권 시작레벨:270 경험치:15.5 개수:10000 버닝:X
```

제공받은 최신 표를 기준으로 일반 EXP 교환권은 Lv.200~260, 상급 EXP 교환권은 Lv.260~299에서 계산합니다. 버닝은 `X`, `하이퍼버닝`, `비욘드버닝` 중 하나를 선택하며 각각 Lv.260과 Lv.270에서 정확히 끝납니다. 버닝을 생략하면 사용자별로 마지막에 선택한 값을 다시 사용하고, 저장된 값이 없는 첫 사용자는 `X`를 기본으로 적용합니다. 선택값은 봇이 재시작되어도 유지되도록 Discord 사용자 ID와 함께 `state.json`에 저장합니다. 결과 제목에는 일반 교환권은 EV, 상급 교환권은 AEV 커스텀 이모지를 표시합니다. 사용 가능한 마지막 레벨을 넘거나 Lv.300에 도달하면 남은 교환권은 적용하지 않습니다.

## 에픽 던전 경험치 계산 명령어

`/에픽던전`에서 던전, 현재 레벨, 현재 경험치 퍼센트, 경험치 보너스를 선택하면 완료 후 레벨과 경험치를 계산하고 솔 에르다 보상을 함께 표시합니다.

```text
/에픽던전 던전:앵글러컴퍼니 레벨:275 경험치:30 경험치보너스:2배
```

- 하이마운틴: Lv.260 이상
- 앵글러컴퍼니: Lv.270 이상
- 악몽선경: Lv.280 이상
- 경험치 보너스: 1.5배, 2배, 2.5배

Lv.294 이상은 각 표의 마지막 고정 경험치를 사용하며, 계산 결과는 Lv.300에서 멈춥니다.

## 아케인·어센틱 심볼 계산기

`/심볼계산기`에서 지역, 현재 레벨·성장치, 목표 레벨, 보약 레벨과 엘라노스 적용 여부를 선택하면 추가로 필요한 심볼 개수와 강화 메소, 일일 퀘스트 기준 예상 완료일을 계산합니다. 심볼 종류는 선택한 지역으로 자동 판별합니다. 보약 레벨과 엘라노스를 생략하면 사용자별 마지막 선택값을 사용하며, 저장값이 없는 첫 사용은 보약 없음·엘라노스 미적용을 기본으로 적용합니다. 선택값은 Discord 사용자 ID와 함께 `state.json`에 저장되어 봇 재시작 후에도 유지됩니다.

```text
/심볼계산기 지역:세르니움 현재레벨:3 현재성장치:50 목표레벨:11 보약레벨:6레벨 엘라노스:적용
```

- 아케인 심볼: 일일 기본 20개, 최대 Lv.20
- 어센틱·그랜드 어센틱 심볼: 일일 기본 10개, 최대 Lv.11
- 보약: 없음 또는 1~6레벨
- 엘라노스 적용: `(기본 심볼 + 보약 보너스) × 120%`의 소수점을 버립니다.
- 엘라노스 미적용: `기본 심볼 + 보약 보너스`를 지급량으로 사용합니다.
- 아케인 심볼: 일일퀘만 수행한 경우와 지역별 주간퀘 120개를 이번 주에 수행한 경우·수행하지 않은 경우를 함께 표시합니다.

선택한 조건은 2026년 9월 8일 23:59 UTC까지만 계산하며, 이후에는 보약과 20% 추가 지급을 제외한 기본 심볼 개수만 적용합니다. 예상 완료일은 명령어를 실행한 날의 일일 퀘스트와 이번 주 주간 퀘스트를 아직 받지 않은 성장치로 계산합니다. 주간퀘 120개에는 엘라노스와 보약 보너스를 적용하지 않습니다.

## 명령어 도움말

`/명령어`는 일반 사용자가 쓸 수 있는 계산기, 시뮬레이터와 일정 확인 명령어를 한 화면에 보여줍니다. 안내는 명령어를 실행한 사용자에게만 표시됩니다.

### 개인 Discord 계정에 명령어 설치하기

공지 자동 전송은 기존처럼 지정한 서버 채널에서만 동작하고, `/명령어`, `/헥사`, `/채널추천`, `/스스비`, `/익성비`, `/성장의비약`, `/exp쿠폰`, `/에픽던전`, `/심볼계산기`, `/아이템검색`, `/5퍼`, `/캐샵`, `/캐시이동`, `/우르스`, `/서버`, `/미라클큐브`, `/핫위크`, `/큐브세일` 명령어는 개인 계정에 설치해 서버와 DM에서 사용할 수 있습니다.

1. Discord Developer Portal의 `Installation`에서 `사용자 설치`와 `길드 설치`를 모두 켭니다.
2. 비공개 애플리케이션은 `설치 링크`를 `없음`으로 둡니다.
3. `OAuth2`의 URL 생성기에서 `applications.commands`와 `User Install`을 선택합니다.
4. 생성된 링크를 열고 `내 앱에 추가`를 선택합니다.

개인 계정에 설치해도 봇 프로그램은 Oracle 서버에서 계속 실행되어야 합니다.

## 프로젝트 파일 구조

- `maple_bot.py`: Discord 명령어, 공지 크롤링, 봇 실행 코드
- `maple_data.py`: 레벨 경험치, 성장의 비약 확률·경험치, EXP 교환권, HEXA 비용표

- `data/cash-items.tsv`: GMS 캐시 아이템과 동일 ID가 있는 KMS 한글 이름

- `tools/update_cash_item_db.ps1`: 패치된 WZ 파일에서 위 두 데이터 파일을 다시 만드는 도구
- `tools/wz_cash_exporter`: WZ 파일을 읽는 추출기와 WzComparerR2 MIT 라이선스 안내

## 처음 설치하기

PowerShell을 열고 프로젝트 폴더로 이동합니다.

```powershell
cd "D:\Code\파이썬\maplestory-discord-bot"
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

생성된 `.env` 파일을 메모장으로 열고 아래 다섯 값을 실제 값으로 바꿉니다.

```env
DISCORD_TOKEN=Discord_봇_토큰
DISCORD_CHANNEL_ID=알림을_보낼_채널_ID
SUNNY_SUNDAY_CHANNEL_ID=Sunny_Sunday_전용_채널_ID
OPENAI_API_KEY=OpenAI_API_키
GOOGLE_TRANSLATE_API_KEY=Google_번역_API_키
```

기존 설치를 안전하게 이전하기 위해 처음 한 번은 `DISCORD_CHANNEL_ID`를 공지 알림으로, `SUNNY_SUNDAY_CHANNEL_ID`를 썬데이 당일·목록 알림으로 등록합니다. 이후 채널 설정은 `state.json`에 저장되며 위의 관리자 명령어로만 변경됩니다. `SUNNY_SUNDAY_CHANNEL_ID`가 비어 있으면 두 썬데이 알림도 기존 `DISCORD_CHANNEL_ID`에서 시작합니다.

## 실행하기

```powershell
python maple_bot.py
```

처음 실행할 때는 기존 공지를 보내지 않습니다. 그 시점의 공지 목록을 기준으로 저장한 뒤, 이후에 올라오는 새 글만 알립니다.
